# W4 — Present mode, PNG and print (package D) — for using the dashboard in work presentations

1. `Present` toggle (top-bar button + `P` key, URL `present=1`): hides the sidebar, toolbars collapse to one thin
   line (indicator name, period, area), numbers +25 % size, legends expanded, a one-line source footer
   ("Source: Tilastokeskus … · as of … · real-estate-war-lord.github.io/am-dashboard-fi") at the bottom. Works on
   Map, Area page, Test property and Charts; Esc leaves. Nothing is removed from the data.
2. `⤓ PNG` on the study row (area page + property): one image of chart + minimap side by side at 2× scale with
   title, legend and the source footer. Use the existing chart PNG export and draw the Leaflet map from its tile
   canvas where possible; where tiles are cross-origin, draw the polygons on a plain paper background (no basemap)
   and say "basemap omitted" in the footer. No external libraries unless already vendored.
3. Print stylesheet (A4 landscape): sidebar and controls hidden, one view per page, source footer, no clipped maps.
Checks (phase W4): present=1 hides the sidebar and shows the source footer on the four views; P toggles; PNG
button produces a download with non-zero size; print media emulation shows no sidebar.
