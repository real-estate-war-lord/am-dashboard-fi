# W2 — Maps and charts readable at a glance (package B)

1. Main map fit: Finland is tall, the map card is wide — half the map is empty grey. Make the map card taller
   (fill the viewport below the toolbar, min 560 px at 1366×768) and fit Finland tightly (bounds padding small,
   fractional zoom). Drilled kunta views fit the kunta. Check 1366, 1440, 1536, 390.
2. Mini-map legends (area page, property page, sheets) cover 40–60 % of the map. In mini-maps, legends start
   collapsed as one `Legend ▾` pill (bottom-left, never over the + / − or ⤢ controls); expanding shows the stack,
   max 50 % of the map height, scrolling inside. The main map keeps expanded legends but never > 60 % height.
3. Charts (area page, property, Charts view, PNG):
   a) "nice" axis ticks (1, 2, 2.5, 5 × 10^n), always including 0 when the range crosses 0; a visible zero line
      for signed indicators;
   b) outlier-proof scale: when a series has a geography break (e.g. the osa-alue median jumping +17,6 % / −7,8 %
      in 2011–2012), the y-range is set from the years all plotted series share, points outside are clipped with a
      small ▲/▼ marker and a note "scale excludes 2011–2012 (area boundaries changed)"; never silently drop data;
   c) x-axis starts at the first year any plotted series has a value (no empty 2011–2013 band when the area starts 2014).
4. One title, not two: the chart card heading repeats the picker ("POPULATION GROWTH" under "Growth ▾") — keep the
   picker, make the card heading the area + period ("Helsinki · 2011–2025"), unit once.
5. The info strip says "postal-code level" while the national map shows municipalities → it names the level
   actually drawn, and changes when zooming in draws postal codes.
Checks (phase W2) for each item (tick values include 0; zero line exists; no legend covers > 50 % of a minimap
at load; map card height ≥ 560 at 1366×768; info strip level text matches the drawn layer).
