# V6 — Responsive, number rules, accessibility, states

Everything the audit assigns to V6: no horizontal overflow and zero JS errors on every route at 1366×768,
1440×900, 1536×864, 390×844; drawer behaviour; legends collapse to a pill on mobile; one `fmt()` path for all
numbers (fi-FI, signed changes, pp vs %, units on the number, "#n of N", `–` for missing, never 0); focus rings,
aria-expanded on every trigger, keyboard open/close of picker, Layers and Export; empty / loading / error state
cards with nouns, never a bare spinner. Checks (phase V6) sweep every route × width.
